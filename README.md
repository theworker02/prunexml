# prunexml

Prune CSV/TSV xml tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/prunexml/

## Install / run

```bash
git clone https://github.com/theworker02/prunexml.git
cd prunexml
node src/cli.js
node --test
```
